# 🎵 MJ Player

> Персональное веб-радио и скробблер Last.fm в стиле Spotify с возможностью сборки в Android APK.

**MJ Player** собирает треки из твоей библиотеки Last.fm, персонального микса или рекомендаций, подбирает к ним аудио через YouTube и автоматически отправляет скробблы в твой профиль.

## ✨ Возможности

- **3 радиостанции**:
  - *Play Your Library* — топ-треки и недавняя история из Last.fm.
  - *Play Your Mix* — умный микс библиотеки и похожих треков.
  - *Recommendations* — новые музыкальные открытия на основе любимых артистов.
- **Полноценный скробблинг**: автоматическая запись прослушиваний в Last.fm и кнопка «Любимый трек» ❤️.
- **Фоновое воспроизведение**: поддержка работы со смартфона и управления через системную шторку уведомлений.
- **Безопасная архитектура**: никаких секретных ключей в открытом коде — все данные вводятся через модальное окно настроек и хранятся локально на твоем устройстве (`localStorage`).
- **Мобильная адаптивность & PWA**: приложение адаптировано под телефоны и легко упаковывается в `.apk`.

## 🛠️ Быстрый старт

1. Склонируйте или скачайте репозиторий.
2. Для локального тестирования запустите сервер (например, через Python):
   ```bash
   python -m http.server 8000
   ```
3. Откройте `http://localhost:8000` в браузере.
4. При первом запуске откроется окно настроек — введите ваш логин Last.fm и API Key.

## 📱 Создание Android APK

Проект содержит встроенный PWA-манифест. Вы можете задеплоить его на любой статический хостинг (например, GitHub Pages, Netlify или Vercel), а затем сгенерировать установочный `.apk` файл через [PWABuilder](https://www.pwabuilder.com/).
